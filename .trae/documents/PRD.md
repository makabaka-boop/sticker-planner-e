# 手账贴纸主题整理页 - 产品需求文档 (PRD)

## 1. 产品概述
一款基于 Vue3 的纯前端手账贴纸主题管理工具，帮助活动组织者和手账爱好者在活动前规划贴纸包、主题卡及完成进度。
- 解决贴纸主题混乱、准备进度不透明、小组分配不清晰的问题
- 目标用户：手账活动组织者、社团负责人、手账工作室

## 2. 核心功能

### 2.1 功能模块
1. **主题管理主页**：主题列表展示、多维度筛选、统计概览
2. **主题详情侧边栏**：单条记录详情、备注维护、待办摘要
3. **批量操作栏**：批量状态修改、复制、删除
4. **活动包预览模式**：小组贴纸包清单、缺口提醒

### 2.2 页面详情
| 页面名称 | 模块名称 | 功能描述 |
|---------|---------|---------|
| 主题管理主页 | 统计头部 | 显示主题总数、各状态数量、贴纸总数、预估总用时 |
| 主题管理主页 | 智能提示中心 | 自动提示：贴纸数量不足、主题名重复、同色系集中、用时过长、备注缺失 |
| 主题管理主页 | 筛选栏 | 按色系、页型、难度、状态、责任人筛选，支持关键词搜索 |
| 主题管理主页 | 主题卡片列表 | 卡片展示主题信息，支持拖拽排序、复选框选择、点击查看详情 |
| 主题管理主页 | 批量操作栏 | 选中记录后显示：批量改状态、批量复制、批量删除 |
| 主题详情侧边栏 | 基础信息 | 展示主题名、色系、贴纸数量、适合页型、示例说明、难度、预计用时、责任人、状态 |
| 主题详情侧边栏 | 备注编辑 | 富文本/多行文本编辑临时备注 |
| 主题详情侧边栏 | 待办摘要 | 待办事项列表，可勾选完成 |
| 活动包预览页 | 小组配置 | 设置参与小组数量、每组贴纸配额 |
| 活动包预览页 | 清单生成 | 按当前筛选结果生成每个小组的贴纸包清单 |
| 活动包预览页 | 缺口提醒 | 标注数量不足或缺失的主题 |

## 3. 核心流程

用户打开页面后可以：
1. 浏览已保存的贴纸主题记录
2. 通过筛选找到特定主题
3. 新增/编辑/复制/删除主题
4. 拖拽调整展示顺序
5. 批量更新状态
6. 点击主题查看详情并编辑备注/待办
7. 切换到活动包预览模式查看分配情况
8. 数据自动保存到浏览器本地存储

## 4. 用户界面设计

### 4.1 设计风格
- **主题色调**：温暖手账风，奶油白底色，搭配柔和马卡龙色系（蜜桃粉、薄荷绿、鹅黄、薰衣草紫）
- **视觉风格**：可爱贴纸感，圆角卡片、柔和阴影、手绘风装饰元素
- **字体**：使用圆润可爱的中文字体，标题稍大加粗，正文清晰易读
- **布局**：左侧主内容区 + 右侧抽屉式详情面板，顶部固定筛选和操作栏
- **图标**：使用线性图标配合可爱贴纸装饰
- **状态标签**：不同颜色的圆角徽章区分状态

### 4.2 页面设计概览
| 页面名称 | 模块名称 | UI 元素 |
|---------|---------|---------|
| 主题管理主页 | 统计头部 | 渐变背景、数字动效、图标+文字横向排列 |
| 主题管理主页 | 智能提示 | 彩色提示卡片、警告图标、关闭按钮 |
| 主题管理主页 | 筛选栏 | 下拉选择器、标签式筛选、搜索框 |
| 主题管理主页 | 主题卡片 | 圆角大卡片、色系圆点、难度星级、状态徽章、拖拽手柄 |
| 主题详情侧边栏 | 详情面板 | 右侧滑入动画、分区块信息展示 |
| 活动包预览 | 预览页 | 网格布局小组卡片、缺口红色标记、打印友好样式 |

### 4.3 响应式设计
- 桌面端优先设计，支持 1280px+ 最佳展示
- 平板端自适应两列/单列布局
- 移动端单列堆叠，详情面板改为全屏弹出

## 5. 数据字段定义

每条主题记录包含：
| 字段 | 类型 | 说明 |
|-----|------|------|
| id | string | 唯一标识 |
| themeName | string | 主题名称 |
| colorScheme | string | 色系（蜜桃粉/薄荷绿/鹅黄/薰衣草紫/天空蓝/奶油白/其他） |
| stickerCount | number | 贴纸数量 |
| pageTypes | string[] | 适合页型（封面/扉页/月计划/周计划/日记录/拼贴页/装饰页） |
| exampleDesc | string | 示例说明 |
| difficulty | number | 难度（1-5星） |
| estimatedTime | number | 预计用时（分钟） |
| assignee | string | 责任人 |
| status | string | 状态（待整理/可使用/需补充/仅展示/暂缓） |
| notes | string | 临时备注 |
| todos | array | 待办事项 [{text, done}] |
| order | number | 排序序号 |
| createdAt | string | 创建时间 |
| updatedAt | string | 更新时间 |
